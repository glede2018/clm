# 减脂拉锯战

原生微信小程序 + TypeScript + 微信云开发实现的减脂配餐工具。用户填写身体资料及每周运动量后，系统计算每日碳水、蛋白质和脂肪目标；用户选择当前拥有的食材，系统返回本餐各食材的生重克数。

## 已实现

- 微信授权登录，按 OpenID 自动创建包含大小写字母和数字的 8 位用户名，未登录用户无法进入业务页面
- 用户主动修改用户名时可选择微信昵称，无需头像授权
- 两屏初始化流程：身体信息一屏，饮食与运动习惯一屏
- 每日拉锯进度与持续打卡
- 首页餐次栏直接展示已打卡食材及生重克数
- 根据性别、体重和每周运动档位计算每日碳蛋脂
- 三餐模式：早餐 25%、中餐 40%、晚餐 35%
- 两餐模式：中餐 55%、晚餐 45%
- 全天通用食材池，早餐、中餐、晚餐均可自由选择
- 生重克重优化与营养匹配度
- 中餐烹调油显式计算，避免低脂肉类导致脂肪漏算
- 根据性别与 BMI 粗略变化的首页角色
- 完成餐食后的角色、彩屑与拉锯动画
- 体重记录及近 7 天执行报告
- 用户邀请码、双向绑定和任意一方解除授权
- 绑定用户之间互相查看当日餐食克重和体重趋势
- 云环境不可用时使用本地存储预览主流程

## 本地开发

1. 安装依赖：

   ```bash
   npm install
   ```

2. 用微信开发者工具导入仓库根目录。项目配置已指定：

   - 小程序目录：`miniprogram/`
   - 云函数目录：`cloudfunctions/`
   - TypeScript 编译插件

3. 在开发者工具中选择或创建云开发环境。

4. 在云开发控制台创建以下集合：

   - `users`
   - `meal_records`
   - `weight_records`
   - `coach_bindings`
   - `coach_invites`

5. 将上述集合的客户端权限设为“所有用户不可读写”。数据统一通过 `api` 云函数按 OpenID 和双向绑定关系访问。

6. 在开发者工具中右键 `cloudfunctions/api`，选择“上传并部署：云端安装依赖”。

7. 建议建立索引：

   - `meal_records`: `ownerId` 升序 + `date` 降序
   - `weight_records`: `ownerId` 升序 + `date` 降序
   - `coach_bindings`: 分别为 `userA`、`userB` 建立单字段索引

未部署云函数时，资料、配餐、首页和报告仍可使用本地数据预览；跨账号绑定必须部署云函数后才能使用。

## 当前营养规则

| 每周运动量 | 男碳水 | 女碳水 | 蛋白质 | 男脂肪 | 女脂肪 |
|---|---:|---:|---:|---:|---:|
| 2–3 小时 / 2 次 | 2.2 | 2.0 | 1.4 | 0.8 | 1.0 |
| 4–5 小时 / 3 次 | 2.5 | 2.2 | 1.6 | 0.9 | 1.1 |
| 6–7 小时 / 4 次 | 3.0 | 2.5 | 1.7 | 1.0 | 1.1 |
| 8–10 小时 / 5 次 | 3.5 | 3.0 | 1.8 | 1.0 | 1.2 |

单位均为 `g / kg 体重 / 天`。运动时长与次数落在不同档位时，采用较低档位。

## 产品与数据说明

- 需烹饪食材营养值以每 100g 烹饪前可食部分记录；面包、牛奶、酸奶等即食食品按实际食用重量记录。
- 当前食物营养数据为工程初始值，上线前需要营养专业人员复核并标注数据来源。
- 肉类、鱼虾应按去皮去骨后的生重可食部分称量。
- 该产品用于一般健康管理，不替代医生、注册营养师或其他专业医疗建议。
- 当前版本限制 18 岁以上用户；孕期、哺乳期、慢性疾病和饮食障碍人群需要专业指导。
