# 食克有数 · 20 秒产品推广片

- 画幅：1080 × 1920，9:16
- 时长：20 秒，30 fps
- 风格：浅奶油色、珊瑚橙、温暖轻快
- 音频：原创合成木琴风格配乐，无旁白
- 界面：依照项目 WXML 和 WXSS 重排的功能演示，非实际录屏；数字为示例。

## 分镜

| 时间 | 内容 |
|---|---|
| 0–1.2 秒 | 品牌封面从第一帧完整显示，随后柔和淡入正文 |
| 1.2–4.4 秒 | 新版营养面板、横向餐食卡片和全局体重入口 |
| 4.4–7.6 秒 | 选食材，生成生重克数方案 |
| 7.6–10.7 秒 | 人体图选择胸部肌群 |
| 10.7–13.7 秒 | 选择哑铃、长凳与 30 分钟参考时长 |
| 13.7–16.8 秒 | 生成优先匹配动作：哑铃卧推，3 组 × 12 次 |
| 16.8–20 秒 | 品牌与行动文案 |

## 编辑与导出

需要 Node.js 22+、Chrome 和 FFmpeg。

```sh
npm run dev
npm run check
npm run render -- --output renders/clm-promo-20s.mp4 --fps 30 --quality high
```

入口为 index.html，设计规则在 DESIGN.md。GSAP、品牌图和配乐均保存在 assets/。
